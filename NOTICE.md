## Twemoji Country Flags font

`public/fonts/TwemojiCountryFlags.woff2` is a subset of the "Twemoji Mozilla"
color font, built by the [country-flag-emoji-polyfill](https://github.com/talkjs/country-flag-emoji-polyfill)
project (MIT-licensed code) from emoji artwork originally created by
[Twemoji](https://github.com/twitter/twemoji).

The emoji artwork is © Twitter, Inc and other contributors, licensed under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). No changes were
made to the artwork itself beyond subsetting the font to the flag glyphs.

## Nerd Font Symbols font

`public/fonts/NerdFontSymbols.woff2` is a subset of "Symbols Nerd Font Mono"
from the [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) project
(v3.5.1), used as a terminal-only fallback so prompt/statusline icon glyphs
(Powerlevel10k, Starship, etc) render even when the user's configured font
doesn't include them. No changes were made to the glyphs themselves beyond
subsetting and hint/layout-table stripping for size.
